# 🤖 Mini AI Chatbot

A simple AI-inspired chatbot built using Java that interacts through the command line.

---

## 🚀 Features

* 💬 Interactive chat
* 🧠 Keyword-based responses
* ⏰ Shows current time
* ❌ Exit command

---

## 🛠️ Tech Stack

* Java
* CLI (Command Line Interface)

---

## ▶️ How to Run

```bash
javac ChatBot.java
java ChatBot
```

---

## 📸 Demo

```text

You: hello
Bot: Hey there! 😊
```
